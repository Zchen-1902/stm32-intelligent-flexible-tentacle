# PCB 硬件设计

本目录保存多触手智能柔性末端执行器的三套 PCB 工程源文件。工程采用嘉立创 EDA 专业版 `.eprj2` 格式，保留原理图、PCB、工程结构及元件信息。

## 文件结构

| 目录 | 工程文件 | 主要用途 |
|---|---|---|
| `H7主控板` | `h743vit6.eprj2` | STM32H743 上层主控、感知、通信、存储和端侧模型部署 |
| `编码器板与SPI转接板` | `编码器.eprj2` | 磁编码器安装及多路 SPI 信号转接 |
| `驱动板与电源板` | `FOC无刷驱动板.eprj2` | STM32G474 三电机 FOC、栅极驱动、电流采样及系统供电相关电路 |

各子目录仅保存最终 PCB 工程文件，不包含嘉立创 EDA 自动生成的 `_backup` 历史压缩包。

## 打开方式

1. 安装嘉立创 EDA 专业版。
2. 在软件中打开或导入对应的 `.eprj2` 工程文件。
3. 检查工程中的原理图、PCB 页面、封装和网络连接。
4. 如需生产，重新生成当前版本的 Gerber、钻孔、坐标和 BOM 文件。

## 使用注意

- PCB 工程记录的是本项目样机所用硬件版本，不代表未经检查即可直接批量生产。
- 下单前应重新执行 ERC/DRC，并核对板层、铜厚、过孔、电源线宽和高电流回路。
- 应根据当前采购器件重新检查封装、替代料和 BOM，不直接沿用历史物料状态。
- 烧录或上电前应核对板卡版本与固件中的引脚、CAN 节点及板级参数配置。
- 历史自动备份仍保留在本地材料目录，未纳入公开仓库。
