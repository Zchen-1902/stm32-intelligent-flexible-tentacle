# 编码器板与 SPI 转接板

## 文件

- `编码器.eprj2`：嘉立创 EDA 专业版工程源文件。

## 作用

该工程用于触手电机位置反馈链路，包含磁编码器相关电路及 SPI 信号转接设计，为三电机控制器提供机械角度、多圈位置和速度计算所需的原始反馈。

## 与软件的对应关系

- G4 编码器驱动：`firmware/g4-motor-controller/Core/spi_encoder`
- G4 控制工程：`firmware/g4-motor-controller`

装配前应核对磁体方向、编码器安装间隙、供电电压、SPI 电平、片选编号和连接器针序。多路编码器共用总线时，必须确认各片选不会同时有效。
